# SmartMaps

## Project Overview  

SmartMaps is an all-in-one trip planning tool.  

---

## Features  

- Plans entire trips based on weather. 

---

## Setup Instructions  

### Prerequisites  

- Python 3.10  

To setup:

1) I recommend setting up a venv like so: python3 -m venv venv
2) Activate the venv: source venv/bin/activate
3) pip install -r requirements.txt
